## 1. 安装与启动

| 版本 | 启动方式 | 说明 |
|---|---|---|
| 网页版 | 双击 `线性代数计算器.html`，用 Chrome / Edge / Safari 打开 | 单文件，所有代码已内联。断网也能算，除 OCR 外的功能不受影响 |
| 在线版（推荐手机用） | Safari / Chrome 打开 `https://<账号>.github.io/<仓库名>/` | 可「添加到主屏」当 App 用；iPhone 上**建议一定加**，见下方说明 |
| 安卓版 | 安装 `线性代数计算器.apk` 后打开 | 仅申请「网络」权限，用于图片识别；其余计算全在本机完成 |

**iPhone / iPad 为什么一定要加到主屏**：Safari 标签页里的本地数据（OCR 的 API Key、分数模式偏好）在 7 个「使用日」没有交互后会被系统清掉；从主屏图标启动的 Web App 使用独立存储，不受这条规则影响。iOS 上一旦检测到你在标签页里用，页面底部会自动弹出「添加到主屏」的引导条，按提示三步即可；OCR 设置对话框里也会再提示一次。

**第一次使用建议**：先打开「矩阵运算 → 单矩阵运算」，点「示例填充」再点「行列式 det」，确认能看到结果与计算步骤，说明运行正常。

## 3. 通用输入规则

### 3.1 单元格可以填什么

| 输入 | 是否支持 | 说明 |
|---|---|---|
| `3`、`-7`、`0` | ✅ | 整数 |
| `1/3`、`-5/2` | ✅ | 分数，会先约分 |
| `0.25`、`-1.5` | ✅ | 小数，自动转成精确分数（`0.25 → 1/4`） |
| `2^3`、`1/2/3`、`π`、`sin(1)` | ❌ | 单元格是数值，不接受表达式；符号表达式请用「符号运算」模块 |
| `1/0` | ❌ | 分母为 0，该格保持原值 |

输入非法时**不会写进矩阵**：输入框会变红并保持编辑状态，改成合法值后按回车（或点击别处）才提交；按 `Esc` 放弃本次修改。

### 3.2 矩阵编辑器

数值矩阵卡片上方有一排按钮：

| 按钮 | 作用 |
|---|---|
| `− 行` / `+ 行` | 增删行，范围 1–10 行 |
| `− 列` / `+ 列` | 增删列，范围 1–10 列 |
| 零矩阵 | 用 0 填满当前尺寸 |
| 单位阵 | 生成同阶单位矩阵（仅方阵可点） |
| 随机 | 填充 −9 到 9 的随机整数，便于试算 |
| 转置填充 | 用当前矩阵的转置替换（行列互换） |

此外还有「示例填充」和「清空」，位于卡片标题右侧。

### 3.3 尺寸与能力速查

| 模块 | 行 | 列 |
|---|---|---|
| 数值矩阵 | 1–10 | 1–10 |
| 符号矩阵 | 2–6 | 2–6 |
| 增广矩阵（方程组） | 1–10（＝方程数） | 2–11（＝未知数 1–10 再加常数列） |
| 向量 | 2–5 维 | — |

## 4. 矩阵运算

### 4.1 单矩阵运算

输入一个矩阵后，点右侧任一运算按钮，结果立即出现在右侧卡片。

| 按钮 | 数学含义 | 前置条件 | 结果形式 |
|---|---|---|---|
| 行列式 det | det A | 方阵 | 精确值（分数） |
| 逆矩阵 | A⁻¹ | 方阵且可逆 | 矩阵；不可逆时提示「该矩阵不可逆（奇异矩阵），行列式为 0」 |
| 秩 rank | rank A | 无 | 整数 |
| 转置 Aᵀ | Aᵀ | 无 | 矩阵 |
| 行最简形 RREF | 行最简形 | 无 | 矩阵 + 主元列说明 |
| 特征值/向量 | λ 与特征向量 | 方阵，且 ≤ 5 阶 | 特征值列表 + 每个特征值对应的特征向量（近似值） |
| 迹 tr | tr A = Σ aᵢᵢ | 方阵 | 精确值 |
| 幂 Aⁿ | Aⁿ | 方阵；n 为整数 | 矩阵；n < 0 需可逆 |

**不满足前置条件的按钮是灰的**（鼠标悬停会显示「仅适用于方阵」）。注意：在非方阵上点「行列式」，除按钮禁用外，逻辑层也会再拦一次并报「行列式仅适用于方阵」。

#### 幂 Aⁿ 怎么用

点「幂 Aⁿ」后弹出指数输入框，输入整数（如 `5`、`-2`、`0`）再点计算：

- n > 0：快速幂，n = 0 得单位矩阵；
- n < 0：先求逆再取正幂，因此矩阵必须可逆；
- 非整数（`1.5`）报「请输入有效的整数指数」。

#### 计算步骤

行列式、逆矩阵、RREF、方程组都会附「计算步骤」面板，可逐条展开查看每一步的行变换，记号约定：

| 记号 | 含义 |
|---|---|
| `R1 ↔ R2` | 交换第 1、2 行 |
| `R2 ← R2 × 1/3` | 第 2 行乘以 1/3 |
| `R3 ← R3 − 2R1` | 第 3 行减去第 1 行的 2 倍 |

逆矩阵的步骤是以 [A | I] 为起点做的，所以面板里会看到一个增广矩阵。

**示例**

```
A = 1  2  3
    4  5  6
    7  8 10
```

- det(A) = −3
- rank(A) = 3
- tr(A) = 16
- 逆矩阵可用（det ≠ 0）

### 4.2 双矩阵运算

分别填好「矩阵 A」和「矩阵 B」，卡片下方会实时显示维度是否匹配：

| 运算 | 按钮 | 条件 | 提示文案（不匹配时） |
|---|---|---|---|
| 加法 | `A + B` | A、B 同型 | 矩阵加法要求同型矩阵。A 为 m×n，B 为 p×q |
| 减法 | `A − B` | A、B 同型 | 矩阵减法要求同型矩阵。A 为 m×n，B 为 p×q |
| 乘法 | `A × B` | A 的列数 = B 的行数 | 矩阵乘法要求 A 的列数等于 B 的行数。A 为 m×n，B 为 p×q |

匹配状态用绿色 `✓ 维度匹配` / 红色 `✗ 维度不匹配` 标出，「示例填充」会给出**乘法可算、加减不可算**的一组（A: 2×3，B: 3×2），正好用来体会维度规则。

结果卡会显示形如 `2×3 × 3×2 = 2×2` 的维度说明。

### 4.3 符号运算

用于带字母的矩阵，例如

```
A = a   b   c
    d   e   f
    g   h   i
```

#### 输入语法

| 语法 | 说明 | 例子 |
|---|---|---|
| 字母变量 | 单字母或字母+数字 | `a`、`x1`、`y2` |
| π | 写作 `pi` 或 `π` | `2*pi` |
| 四则运算 | `+` `-` `*` `/` | `2*a+3`、`a/b` |
| 乘方 | `^` | `x^2` |
| 括号 | `(` `)` | `(a+b)*(c-d)` |
| 乘号 | 建议显式写 `*` | `2*a` 而不是 `2a`（后者可能被解析成变量名） |

支持 `×` `÷` 符号输入，内部会转成 `*` `/`。**不支持**三角函数、对数、开方等函数调用。

#### 可用的运算

| 运算 | 上限 | 结果 |
|---|---|---|
| 行列式 det | 方阵且 ≤ 3 阶 | 化简后的多项式，如 `a*d - b*c` |
| 逆矩阵 | 方阵且 ≤ 3 阶 | 分式矩阵；奇异时提示不可逆 |
| 秩 rank | 6×6 | 整数 |
| 转置 Aᵀ | 6×6 | 矩阵 |
| 行最简形 RREF | ≤ 4×4 | 矩阵 + 秩 + 主元列 |
| 迹 tr | 方阵 | 表达式 |

超出上限会明确报错（如「符号行列式最多支持 3 阶矩阵」），这是符号化简复杂度爆炸的工程折中。

## 5. 线性方程组

把方程组写成**增广矩阵** [A | b] 输入。默认列标题为 `x1 x2 … xn | b`，最后一列是常数列。

```
 2x₁ +  x₂ −  x₃ =  8
−3x₁ −  x₂ + 2x₃ = −11      →    [ 2  1 -1 |  8 ]
−2x₁ +  x₂ + 2x₃ = −3            [-3 -1  2 | -11 ]
                                  [-2  1  2 | -3 ]
```

### 5.1 尺寸控制

| 控件 | 范围 | 说明 |
|---|---|---|
| 方程数 | 1–10 | 即行数 |
| 未知数 | 1–10 | 即列数 − 1（列数 2–11）；改未知数时增减的总是增广列之前的部分，`b` 列始终留在最后 |

### 5.2 求解与结果

点「求解」后，右侧「求解结果」卡片给出三种结论之一：

| 结论 | 界面表现 | 含义 |
|---|---|---|
| **唯一解** | 绿色标题 + 各变量取值 | rank A = rank [A∣b] = n |
| **无穷多解** | 黄色标题 + 自由变量列表 + 特解 + 基础解系 η | 秩相等但小于未知数个数 n |
| **无解** | 红色标题 + 「方程组存在矛盾方程，没有解。」 + 秩对比说明 | rank A ≠ rank [A∣b]，消元后出现 `0 = 非零常数` 的矛盾行 |

> **关于秩的显示（v1.2 已修复）**：早先版本这句话里的两个秩会打印成同一个值（例如 `1 和 1`）。当前产物由源码重新构建，无解时会正确显示 `系数矩阵秩 = 1，增广矩阵秩 = 2，秩不相等故无解`。若你手上的副本仍是旧版，重新构建或取最新产物即可。

无穷多解的通解形式为：

x = 特解 + c₁η₁ + c₂η₂ + ⋯

界面会分别给出「通解形式」「自由变量」「基础解系 η」三块内容，可直接抄进作业。

「高斯消元过程」面板展示每一步行变换，增广列前有竖线分隔，方便对照。

### 5.3 快速示例按钮

| 按钮 | 载入的方程 | 结果 |
|---|---|---|
| 唯一解 | 上文 3 元方程组 | x₁ = 2，x₂ = 3，x₃ = −1 |
| 无穷多解 | `x+2y+3z=1`、`2x+4y+6z=2`、`3x+6y+9z=3` | 秩 1，自由变量 x₂、x₃ |
| 无解 | `x+y+z=1`、`2x+2y+3z=2` | rank A = 1、rank [A∣b] = 2 |

> 判断「无解 / 无穷多解」的依据是秩，不是行列式——非方阵或不齐次时，行列式那套判据不适用。

## 6. 向量运算

### 6.1 输入

- 维度可调 **2–5**（调整维度时已有分量保留，缺的补 0）；
- 「向量 v」「向量 w」两组输入，可用「示例填充」载入 v=(1,2,3)、w=(4,5,6)；
- 「清空」把两组都置零。

### 6.2 六种运算

| 按钮 | 公式 | 前置条件 | 输出 |
|---|---|---|---|
| 点积 v·w | Σ vᵢwᵢ | 维度相同 | 精确值（分数模式显示分数） |
| 叉积 v×w | v × w | **仅 3 维** | 向量（与 v、w 都垂直） |
| 长度/模 | ‖v‖ = √(Σ vᵢ²) | — | 两个模长，6 位小数 |
| 单位化 | v̂ = v / ‖v‖ | 非零向量 | 两个单位向量 |
| 夹角 | θ = arccos((v·w) / (‖v‖‖w‖)) | 两个非零向量 | 弧度 + 角度两种表示 |
| 线性组合 | αv + βw | 维度相同 | 向量 |

「线性组合」会先展开两个系数输入框，填系数（支持分数，如 `1/2`）再点计算，标题会显示成 `线性组合 1/2·v + 3·w`。

**维度不足时按钮自动禁用**：叉积在 2 维向量下灰掉，悬停提示「仅三维向量可用」。

**示例（v=(1,2,3)、w=(4,5,6)）**

| 运算 | 结果 |
|---|---|
| 点积 | 32 |
| 叉积 | (−3, 6, −3) |
| 模 | ‖v‖ ≈ 3.741657，‖w‖ ≈ 8.774964 |
| 夹角 | ≈ 0.225726 rad ≈ 12.9332° |

## 7. 图片识别（OCR）

作用：把纸上/截图里的矩阵**拍成图片自动填进输入框**，省去手输十几格。

### 7.1 一次性配置

1. 在任意矩阵卡片标题右侧点「配置 OCR」（单矩阵、双矩阵 A/B、符号矩阵、方程组各有一个）；
2. 填写三项：
   - `Base URL`：接口根地址，需兼容 OpenAI Chat Completions（如 `https://api.openai.com/v1`、`https://api.deepseek.com`）；
   - `API Key`：你自己的密钥；
   - `视觉模型名`：必须支持图像输入（`gpt-4o-mini`、`gpt-4o`、`claude-3-5-sonnet`、`deepseek-flash` 等）；
3. 「保存配置」，按钮由「配置 OCR」变为「图片识别」；旁边会多出一个齿轮按钮「OCR 设置」，之后想改配置点它。

配置存在**浏览器本地**，换浏览器/清缓存/换设备都要重填。密钥明文存储，勿在公用电脑上配置。

### 7.2 识别流程

```
点识别按钮 → 选择/拍摄图片 → 图片编辑（可选）→ 确认并识别 → 自动填入矩阵
```

图片编辑对话框提供：

| 操作 | 说明 |
|---|---|
| 拖动裁剪框 / 拖四角控制点 | 只保留矩阵区域，能显著提升识别率 |
| 左转 / 右转 | 每次 90°，把横拍的照片摆正 |
| 水平翻转 / 垂直翻转 | 处理镜像图 |
| 重置 | 复原旋转、翻转与裁剪框 |
| 确认并识别 | 导出 JPEG 后上传识别 |

**建议**：把矩阵裁到只剩数字与括号，去掉题号、手写批注、阴影；光线均匀、字迹与底色对比明显时准确率最高。

### 7.3 三种识别模式

不同模块调用不同的识别模式，提示词不同：

| 模块 | 模式 | 期望图片内容 |
|---|---|---|
| 矩阵 A / 矩阵 B / 单矩阵 | 数值矩阵 | 纯数字矩阵（含分数、负数） |
| 符号运算 | 符号矩阵 | 含字母、π、运算符的矩阵 |
| 线性方程组 | 增广矩阵 | 增广矩阵，带 `∣` 或虚线分隔常数列 |

### 7.4 识别结果的处理

- 识别成功：直接覆盖当前矩阵，并提示「识别成功：3×3 矩阵」（双矩阵场景为「已识别到矩阵 A」）；
- **部分单元格无法解析**（模型返回了 `1/0`、乱码等）：这些格子被置为 **0**，并弹出「有 N 个单元格识别失败，已置为 0，请核对」——**务必人工核对这几个格子**；
- 行列数校验：模型返回的行数/列数与声明不符时直接报错，不会张冠李戴地填进去；
- 网络错误、鉴权失败、额度耗尽等：显示服务端返回的状态码与内容，例如 `API 请求失败 (401): ...`、`应用额度已耗尽，请联系应用开发者`。

> 识别只是「录入加速器」，不改变计算逻辑。识别后的一切计算仍是本地精确运算。

## 8. 显示、精度与复制

| 项目 | 行为 |
|---|---|
| 分数模式（默认关） | 开：`1/3`、`-5/2`；关：`0.333333`、`-2.5`（6 位小数，去尾零） |
| 行列式 / 逆 / RREF / 幂 / 点积 | 全程精确分数，无浮点误差 |
| 特征值 / 特征向量 | 数值近似，界面有「结果可能存在微小误差」提示 |
| 模长 / 夹角 / 单位向量 | 浮点，6 位小数（角度 4 位） |
| 结果复制 | 每张结果卡右上角有「复制」按钮：复制成**制表符分列**的纯文本，粘到 Excel / WPS 会自动分格。也可以直接框选结果文字手动复制；步骤面板同样是文本，可整段选中 |

**复制出来长什么样**（以 3×3 逆矩阵为例）：

```
1	0	0
0	1/2	-1/2
-1	1	1
```

小数模式下则是对应的小数；若浏览器不允许写剪贴板（例如用 `file://` 双击打开的单文件版被策略拦截），按钮会自动退回到备用的复制方式，仍失败时提示「长按选择文本手动复制」。

**为什么分数模式是默认值之外的可选项**：工程计算、编程作业更习惯小数；线性代数作业核对更关心 `1/7` 这类精确值。两种都保留，随时切换。

## 10. 典型使用流程

**核对作业**（最常用）

1. 矩阵运算 → 单矩阵运算 → 手输矩阵；
2. 点「行列式 det」看值与步骤，与手算比对；
3. 点「计算步骤」逐步核查行变换，找出自己算错的那一步；
4. 顶栏切换到「分数模式」，确认结果是 `1/3` 还是 `0.333333`。

**解方程组**

1. 线性方程组 → 把每行系数与常数填进增广矩阵（列数 = 未知数 + 1）；
2. 「求解」→ 看结论类型；
3. 如果是无穷多解，抄「特解 + 基础解系」；
4. 展开「高斯消元过程」写解题步骤。

**手机快速录入**

1. 拍照 → 识别 → 编辑器里裁掉题号与手写内容；
2. 识别后核对被置 0 的格子；
3. 继续在线计算。

## 11. FAQ

**Q：断网还能用吗？**
A：能。所有计算在前端完成；只有 OCR 需要联网（调你自己配置的模型接口）。网页版首次加载时字体走 CDN，失败会自动回退系统字体，不影响功能。

**Q：数据会上传吗？**
A：计算结果不会。只有 OCR 时，你选中的那张图片会以 base64 发给你配置的模型服务商；API Key 只存在本机 `localStorage`。

**Q：为什么 3 阶以上的特征值有小数尾巴？**
A：n≥3 用 QR 迭代求特征值、反幂法求特征向量，本质是数值方法，容差 1e-10、最多 100 次迭代。要精确值请手算或看 2×2 的解析结果。

**Q：特征值为什么会缺？**
A：3 阶及以上目前只输出实特征值；如果矩阵有复特征值，只有 2×2 会被正确识别为复数对。

**Q：为什么输入 `2a` 没被当成 2×a？**
A：符号解析器把连续字母当作一个变量名。乘号请显式写 `2*a`。

**Q：换手机 / 清缓存后 OCR 配置没了？**
A：配置存在浏览器本地，不会同步。重新填一次即可。

**Q：APK 和网页版有什么区别？**
A：计算逻辑完全一致，共用同一套存储键与配置格式。差别只在交付形态：网页版是单个 HTML（代码全部内联，双击即用），APK 是 Capacitor 壳 + 分块资源（需安装，可离线启动）。
