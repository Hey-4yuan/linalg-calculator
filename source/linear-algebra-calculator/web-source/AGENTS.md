# 线性代数在线计算器 - 需求拆解文档

## 产品概述

- **产品类型**: 在线科学计算工具（线性代数计算器）
- **场景类型**: <scene_type>prototype-app</scene_type>
- **目标用户**: 学生、教师、科研人员及工程技术人员，需要进行线性代数相关计算与学习验证
- **核心价值**: 在浏览器本地完成所有线性代数运算，无需后端，支持步骤展示与分数/小数切换，辅助学习与快速验算
- **界面语言**: 中文
- **主题偏好**: 浅色（未指定，默认 light）
- **导航模式**: 无导航（单页工具，通过 Tab 切换功能模块）
- **导航布局**: 无

## 页面结构总览

> **说明**：本工具为单页应用，通过顶部 Tab 在不同计算模块间切换，所有功能共享同一页面骨架

**页面文件**: `LinearAlgebraCalculator.tsx`

| 区域 | 说明 |
|-----|------|
| 顶部标题栏 | 应用名称 + 分数/小数全局切换开关 |
| 功能 Tab 栏 | 矩阵运算 / 线性方程组 / 向量运算 三个主 Tab |
| 矩阵运算子 Tab | 单矩阵运算 / 双矩阵运算 两个子 Tab |
| 输入区 | 对应功能的矩阵/向量输入网格 + 快捷操作按钮 |
| 结果展示区 | 计算结果（标准数学格式）+ 计算步骤（可展开） |
| 错误提示区 | 非法输入、维度不匹配等友好提示 |

## 页面布局建议

- **布局模式**: 上下分区（顶部 Tab + 中部输入区 + 下部结果区），桌面端矩阵输入与结果可并排，移动端上下堆叠
- **视觉重心**: 输入与结果并重 —— 用户需持续对照输入数据与计算结果，确保准确性
- **结果承载区**: 结果面板（标准数学矩阵排版 + 步骤展开折叠）；初始态为**示例占位**（加载示例矩阵并展示对应结果，让用户第一时间理解工具用途）
- **源材料承载区**: 矩阵输入网格常驻可视，支持动态增删行列，用户计算时无需滚动即可对照

## 功能列表

### 全局功能

- **页面目标**: 提供一站式线性代数计算工具，支持矩阵、方程组、向量三类核心运算
- **功能点**:
  - **功能模块切换**: 顶部 Tab 在「矩阵运算 / 线性方程组 / 向量运算」间切换，子 Tab 在「单矩阵 / 双矩阵」间切换，切换时保留已输入的数据
  - **分数/小数全局切换**: 顶部开关控制所有数值结果以分数形式或小数形式展示，状态持久化到 localStorage
  - **一键清空**: 清空当前模块的所有输入与结果，恢复初始态
  - **示例填充**: 一键填充当前模块的典型示例数据，快速演示功能用法

### 模块一：矩阵运算 - 单矩阵运算

- **页面目标**: 输入一个矩阵，完成行列式、逆、秩、转置、RREF、特征值、迹、幂等运算
- **功能点**:
  - **矩阵输入网格**:
    - 支持自定义行数和列数（2~10 范围内增删行列）
    - 单元格支持输入整数、小数、分数（如 `3/4`、`-2/5`）
    - 输入非法时单元格红框高亮 + 下方错误提示
  - **快捷生成**:
    - 零矩阵、单位矩阵（需方阵）、随机矩阵（整数范围可调）一键生成
    - 转置快捷填充（用当前矩阵的转置结果覆盖输入）
  - **单矩阵运算按钮组**: 行列式(det)、逆矩阵、秩(rank)、转置、行最简形(RREF)、特征值与特征向量、迹、幂(A^n，弹出输入指数 n)
  - **结果展示**:
    - 结果以标准数学矩阵格式排版（括号包围、行列对齐）
    - RREF/高斯消元展示每一步行变换过程（可展开/折叠步骤详情）
    - 逆矩阵不可逆时明确提示「该矩阵不可逆（奇异矩阵）」
    - 特征值结果支持实特征值与复特征值显示

### 模块二：矩阵运算 - 双矩阵运算

- **页面目标**: 输入两个矩阵，完成加法、减法、乘法运算
- **功能点**:
  - **双矩阵输入区**: 并排展示矩阵 A 和矩阵 B 的输入网格，各自可独立调整行列数
  - **维度校验**: 选择运算时自动校验维度匹配性（加减需同型、乘法需 A列=B行），不匹配时弹出友好提示并指出具体维度差异
  - **运算操作**: 加法(A+B)、减法(A−B)、乘法(A×B)三个运算按钮
  - **结果展示**: 结果矩阵标准数学格式排版，支持分数/小数切换；运算过程简要说明（如「3×2 矩阵 × 2×3 矩阵 = 3×3 矩阵」）

### 模块三：线性方程组求解

- **页面目标**: 输入增广矩阵 [A|b]，用高斯消元法求解并判断解的情况
- **功能点**:
  - **增广矩阵输入**: 网格左侧为系数矩阵 A，最后一列为常数列 b，视觉上用竖线分隔
    - 支持自定义行数（方程数）和列数（未知数个数）
  - **高斯消元求解**: 一键求解，自动执行行变换至行最简形
  - **解的判定与展示**:
    - 唯一解：给出每个变量的具体值
    - 无穷多解：指出自由变量，给出通解形式（含基础解系）
    - 无解：明确说明矛盾方程位置
  - **消元过程展示**: 分步展示每一次行变换（如「R₂ ← R₂ − 2R₁」），支持逐步展开与全部展开切换，辅助学习理解

### 模块四：向量运算

- **页面目标**: 完成向量点积、叉积、模、单位化、夹角、线性组合等运算
- **功能点**:
  - **向量输入**: 支持输入 2~5 维向量 v 和 w（维度可调），三维及以上才显示叉积按钮
  - **向量运算按钮组**: 点积(v·w)、叉积(v×w，仅三维可用)、向量长度/模(‖v‖)、单位化(v̂)、向量夹角(θ)、线性组合(a·v + b·w，弹出输入系数 a 和 b)
  - **叉积维度校验**: 非三维向量点击叉积时提示「叉积仅适用于三维向量」
  - **结果展示**: 标量结果（点积、模、夹角）以数值+单位形式展示；向量结果（叉积、单位化、线性组合）以列向量格式排版；夹角同时显示弧度和角度值

## 技术选型建议（供代码实现参考）

> 以下为非约束性建议，由 design/code 阶段按需采纳

- **核心计算库**: 纯前端实现，建议使用 `math.js` 或自研 Fraction 分数运算类保证精确性
- **矩阵渲染**: 使用 CSS Grid 或 HTML Table 实现矩阵括号与单元格对齐
- **分数计算**: 所有运算底层使用分数（分子/分母整数对）计算，展示时再按偏好转小数或保留分数形式
- **新增依赖**: `mathjs`（可选，用于复杂特征值计算等），如追求零依赖可全部自研

# UI 设计指南

## 1. 设计推导依据

- **参考意图**: Free —— 无参考材料，按产品语义自主设计
- **核心情绪 / 应用类型**: 数学工具的精准、清晰、可信赖；面向学习与计算核对的高密度生产力工具
- **独特记忆点**: 矩阵网格以等宽字体细线排版，结果区用淡青数学纸底 + 深墨公式字，配合细微网格点纹呼应线性代数的「坐标与变换」语义

## 2. Art Direction

- **方向名**: 数学稿纸·精密工具
- **Design Style**: Swiss Minimalist + Editorial Math —— 瑞士极简保证信息秩序，数学排版气质承载公式与矩阵阅读
- **DNA 参数**: 圆角 subtle (rounded-md) / 阴影 subtle (shadow-sm) / 间距 standard (gap-4, p-6) / 字体方向：正文无衬线 + 结果区等宽衬线 / 装饰手法：极细边框、淡点纹背景、分数斜杠与矩阵括号的数学排版细节
- **应用类型**: Tool —— 左侧或顶部功能切换 + 右侧输入区 + 下方结果区的任务型布局

## 3. Color System

**色彩关系**: 深靛蓝主色 + 数学纸米白底 + 淡青灰辅助底 + 墨蓝文字，整体低饱和、高对比，接近教材印刷质感
**配色设计理由**: primary 用于功能切换激活态、主计算按钮与关键结果高亮；bg 采用略带暖调的纸白，减轻长时间数字阅读的视觉疲劳；accent 承担 hover、选中浅底与输入聚焦；border 采用冷灰细线，保持数学稿纸的克制感
**主色推导**: 线性代数属于严谨数学学科，选深靛蓝（非刺眼的科技蓝）作为 primary，既表达精确与理性，又区别于通用 SaaS 的亮蓝，更接近教材与学术出版物的视觉传统
**使用比例**: 65% 中性 / 25% 辅助 / 10% primary；primary 仅用于 CTA 按钮、当前功能 tab、关键结果数字；icon 与边框用中性色，链接与辅助高亮用 accent

- 警告（维度不匹配 / 自由变量提示）：hsl(35 70% 40%) 琥珀；三态——bg: hsl(40 80% 95%) / border: hsl(38 65% 70%) / text: hsl(30 70% 35%)
- 错误（非法输入 / 不可逆 / 无解）：hsl(0 55% 45%) 砖红；三态——bg: hsl(0 60% 96%) / border: hsl(0 45% 78%) / text: hsl(0 55% 40%)
- 所有语义色饱和度控制在 40%-70%，与 primary 的 55% 饱和度对齐，避免状态色刺眼跳脱

## 4. 字体与节奏

- **font-display**: Noto Serif SC —— 用于页面标题与结果区关键数学结论，衬线字体呼应数学教材的印刷质感
- **font-body**: Noto Sans SC —— 中文界面正文，清晰易读；矩阵数字与公式区使用 IBM Plex Mono 等宽字体，保证数字对齐
- **字号**: H1 text-3xl ~ text-4xl；H2 text-xl ~ text-2xl；body text-sm ~ text-base；矩阵单元格 text-sm 等宽；muted text-xs ~ text-sm
- **圆角**: 小 (rounded-md) —— 克制圆角，接近印刷稿的方整感，仅按钮与卡片轻微倒角

## 5. 全局布局契约

- **Reference Layout Use**: 按需求结构推导
- **Page / Section Order**: 顶部标题栏 + 功能切换区（单矩阵 / 双矩阵 / 方程组 / 向量）+ 输入面板（矩阵网格与操作按钮）+ 结果展示区（含步骤展开）
- **Standard Content Zone**: max-w-5xl + `mx-auto`，工具型应用保证输入与结果同屏可见
- **Shell / Frame Alignment**: 同宽——内容容器与导航框架共享同一 max-w，视觉上居中对齐
- **Padding & Rhythm**: `px-4 md:px-6 py-8 md:py-10`，区块间距 `gap-6`，保持 4px / 8px 倍数节奏
- **Full-bleed Zones**: 无全宽 Hero；顶部导航栏可全宽但内容受 max-w 约束
- **Local Narrowing**: 向量运算等输入量少的面板可收窄至 `max-w-2xl` 居中
- **Overflow Strategy**: 大矩阵（>5 列）使用 `overflow-x-auto` 横向滚动，不撑开主容器
- **Flexibility Boundary**: 允许移动端调整矩阵单元格字号与内边距、功能 tab 转为横向滚动；不允许切换主色、圆角或阴影语言

## 6. 视觉与动效

- **装饰**: 淡点纹背景（仅结果区）、细线矩阵括号、分数上下排版
- **阴影/边界**: 轻——卡片使用 `shadow-sm`，输入网格以边框分隔为主，避免厚重阴影
- **动效**: 克制——按钮 hover 有背景色过渡（150ms），结果展开有轻量滑入（200ms ease-out），计算按钮点击有微缩放反馈；无多余装饰动效

## 7. 组件原则

- 功能切换使用 tab 样式，激活态用 primary 底 + 白字，未激活用 accent hover
- 矩阵输入单元格为细边框方格，聚焦时 primary 色描边 + 浅 accent 底
- 操作按钮（清空 / 示例 / 生成矩阵）用 outline + ghost 层级，主计算按钮用 solid primary
- 结果卡片采用 card 白底 + border + 轻阴影，内部矩阵用等宽字体居中排版，括号用 CSS 或符号实现而非图片
- 错误提示用带左边界的 alert 样式（错误色竖条 + 浅底），不使用弹框打断输入
- 分数 / 小数切换为分段控件（segmented control），位于结果区右上角

## 8. Image Direction

- **Image Role**: 无
- **Image Art Direction**: 无强制图片需求，视觉记忆点通过排版、矩阵网格、淡点纹背景与数学字体细节建立
- **Image Prompt Keywords**: 无
- **Image Avoidance**: 避免通用科技感插图、无意义几何渐变背景、商务人物素材；不得用图片替代矩阵排版

## 9. Anti-patterns

- **Split personality**: 不同计算功能页使用不同颜色或圆角；全站统一深靛蓝主色与 subtle 圆角系统
- **Matrix as image**: 用图片或截图展示矩阵结果；必须用文字 + 等宽字体 + CSS 括号排版，保证可复制与可访问
- **Default SaaS drift**: 回到亮蓝渐变按钮 + 卡片堆叠的通用后台感；用数学纸底 + 深墨 + 细边框的教材气质塑造差异
- **Invisible interaction**: 矩阵单元格聚焦态缺失；每个可输入格子都要有清晰的 focus-visible 描边
- **Mono-hue tyranny**: 主色同时用于按钮、tab、icon、边框、链接；primary 仅占 10%，其余由 accent 与中性色承担
- **Status color scream**: 错误提示用高饱和大红铺满；语义色饱和度与 primary 对齐，用浅底 + 深字 + 左竖条表达
